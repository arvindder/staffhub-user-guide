Scheduling
==========

The Scheduling feature helps you create and manage staff schedules efficiently.

Creating a Schedule
-------------------

To create a new schedule:

1. Go to the **Scheduling** section
2. Click **New Schedule**
3. Select the date range for your schedule
4. Choose the staff members to include
5. Set shift times and assignments
6. Click **Save Schedule**

Managing Shifts
---------------

You can manage individual shifts in several ways:

* **Drag and Drop**: Move shifts between days and staff members
* **Copy Shifts**: Duplicate shifts to other days
* **Bulk Edit**: Modify multiple shifts at once

Shift Templates
---------------

Create templates to speed up schedule creation:

1. Click **Templates** in the Scheduling section
2. Click **New Template**
3. Define your standard shift patterns
4. Save the template for future use

You can then apply templates when creating new schedules.

Viewing Schedules
-----------------

Schedules can be viewed in multiple formats:

* **Calendar View**: See schedules in a calendar layout
* **List View**: View schedules as a detailed list
* **Timeline View**: See schedules in a timeline format

User Management
===============

The User Management feature allows administrators to create, edit, and manage user accounts in StaffHub.

Creating a New User
-------------------

To create a new user:

1. Navigate to the **Users** section from the main menu
2. Click the **Add New User** button
3. Fill in the required information:

   * First Name
   * Last Name
   * Email Address
   * Role/Position
   * Department

4. Click **Save** to create the user account

Editing User Information
------------------------

To edit an existing user:

1. Go to the **Users** section
2. Find the user you want to edit
3. Click on the user's name or the **Edit** button
4. Modify the information as needed
5. Click **Save** to apply changes

User Roles
----------

StaffHub supports different user roles:

* **Administrator**: Full access to all features
* **Manager**: Can manage schedules and view reports
* **Staff**: Can view their own schedule and submit requests
* **Viewer**: Read-only access

Deleting Users
--------------

.. warning::
   Deleting a user is a permanent action. Make sure you want to proceed.

To delete a user:

1. Navigate to the user's profile page
2. Click the **Delete** button
3. Confirm the deletion in the popup dialog

Tutorial: Managing Time-Off Requests
=====================================

Learn how to handle time-off requests from your staff members.

Submitting a Time-Off Request (Staff)
--------------------------------------

As a staff member:

1. Go to **My Requests** > **Time Off**
2. Click **Request Time Off**
3. Select the dates you need off
4. Choose the request type (Vacation, Sick Leave, Personal, etc.)
5. Add any notes or comments
6. Click **Submit Request**

Approving or Denying Requests (Manager)
----------------------------------------

As a manager:

1. Navigate to **Requests** > **Pending Requests**
2. Review the time-off request details
3. Check for schedule conflicts
4. Click **Approve** or **Deny**
5. Add a comment if needed
6. The staff member will receive a notification

Viewing Time-Off Calendar
--------------------------

To see all time-off requests in a calendar view:

1. Go to **Scheduling** > **Time-Off Calendar**
2. View all approved time-off requests
3. Use filters to view specific departments or date ranges

Best Practices
--------------

* Submit time-off requests as early as possible
* Review requests promptly to keep staff informed
* Consider coverage when approving requests
